ByAzen v3.6.0 — сведения о сборке

Цель: Windows x64 GUI, PE32+.
Исходники: src/byazen_native.cpp, src/click_engine.h; вшитый ресурс интерфейса: src/byazen_ambient_portrait.png (RCDATA, ID 102).
Компилятор приложенного EXE: Zig 0.17.1 (clang + MinGW-w64), кросс-сборка из Linux скриптом build_zig.sh.
Флаги: C++20, -O2, -Wall -Wextra -Werror, -municode, подсистема Windows GUI, статическая libc++.
Отличие от сборок до v3.5.0 (MinGW-w64 GCC): C-рантайм — UCRT (api-ms-win-crt-*, входит в Windows 10 и 11) вместо msvcrt.dll.

Изменения v3.6.0: Target CPS до 1000 (было до 200). Тайминг кликов вынесен в src/click_engine.h: клики идут по абсолютной сетке времени, первый клик уходит сразу после нажатия кнопки активации, кнопка опрашивается каждую 1 мс. Счётчик CPS считается по интервалам между последними кликами (окно 0,5 с), а не по числу кликов за секунду. Удержание укорачивается до 60 % цикла, если не помещается. Burst-старт — не ниже 200 CPS и не ниже Target CPS. Выше 250 CPS активное ожидание включается автоматически. Колесо мыши над ползунком меняет значение на 1 (Shift — на 10); запись в INI откладывается на 0,4 с после последнего шага. Конфигурация: schema v10 без изменений, обратная загрузка v1–v10.

Команда сборки (из каталога src):
zig rc /c65001 resource.rc resource.res
zig c++ -target x86_64-windows-gnu -std=c++20 -O2 -Wall -Wextra -Werror -municode -Wl,--subsystem,windows byazen_native.cpp resource.res -lgdiplus -lgdi32 -luser32 -lshell32 -lwinmm -lole32 -lcomdlg32 -ladvapi32 -o ../ByAzen.exe

Что проверено:
- Строгая компиляция и линковка завершились без предупреждений.
- Тип PE32+ Windows GUI, таблица импортов (только системные библиотеки, ws2_32.dll отсутствует), ресурсы: иконка, artwork, манифест, версия 3.6.0.0.
- tests/click_engine_test.cpp: тот же код тайминга на симулированных часах с опаздывающим таймером. Заданный CPS выдерживается от 5 до 1000, первый клик уходит сразу, зависание системы не вызывает догоняющей очереди кликов.

Что не проверено:
- Запуск EXE в Windows, внешний вид и реальная частота кликов: в среде сборки Windows недоступен.
- Сборка этой версии через build_native.bat (MinGW-w64 GCC) не выполнялась; сам скрипт не менялся.

Бинарник не подписан коммерческим Authenticode-сертификатом. SmartScreen или эвристика антивируса могут показать предупреждение; отсутствие предупреждений не гарантируется.
